FILES
- index.html       Personal introduction / homepage
- reflections.html Weekly reflections index (Week 2, 3, 4, 5)
- week-2.html      Week 2 reflection page
- week-3.html      Week 3 reflection page
- week-4.html      Week 4 reflection page
- week-5.html      Week 5 reflection page
- style.css        All visual styles and responsive layout
- script.js        Small scroll-reveal animation

HOW TO CUSTOMISE
1. Open index.html and replace [Your Name] with your preferred name.
2. Replace [YN] in the header/footer with your initials or a short monogram.
3. Replace the temporary portrait image URL in index.html with your own image. For a local image, put it in an assets folder and use: assets/my-portrait.jpg
4. In reflections.html, change each [Add a short topic or class title] to the real topic for that week.
5. In week-2.html to week-5.html, replace the bracketed prompts with your own class notes and reflections.
6. Replace the example food image URLs with your own class photos. You can put images in assets/ and use paths such as assets/week-2.jpg.

ADDING WEEK 6 OR LATER
1. Copy week-5.html and rename the copy to week-6.html.
2. Change its title, week number, image and text.
3. Add a new week-tile link in reflections.html, linking to week-6.html.
4. Update the previous/next links at the bottom of the weekly pages if needed.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload all files in this folder (keep them together in the same folder level).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site. Open the URL shown in Settings > Pages.

NOTES
- Week 1 is intentionally not included.
- The layout and animations are made with HTML, CSS and a small amount of JavaScript. GitHub Pages supports this.
- External Google Fonts and example Unsplash photos need an internet connection. For a more reliable final submission, you can save your own properly licensed images in the assets folder and use local image paths.
- The visual direction is an original fashion-editorial interpretation: monochrome photography, warm ivory, restrained burgundy, oversized serif typography and subtle motion. It does not copy any fashion house's website or logo.
